 1. How does a nested if differ from an if else statement?
 A nested if statement is am if statement that is within another if statment that only runs if the previous statement is not met. An if else staztement decides what do to when those conditions are either true or false.

 2. What are the advantages of using switch over multiple statements?
 A switch statement makes the code easier and more organized when there multiple possible choices to chose from for one variable. It can also prevent us from writing multiple seperate if else statements.
 
 3. How does the conditional operator simplify decision making?
 The conditional operator ? : lets a simple decision be writen in one line rather than having to use an if else statement. I had to use it to chose between 2 different movie recommendations.

 4. What is short-circut evaluation and how does it affect the use of logical operators?
 Short-circut evaluation is when java can stop checking conditions once it knows the results already. With && java can stop once a condition is false, and with || java will stop once the cpndition is true.
